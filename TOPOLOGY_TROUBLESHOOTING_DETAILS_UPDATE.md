# Topology Troubleshooting Details

The topology now provides detailed hover information without adding permanent
visual clutter.

## Cable hover details

- Connector/cable type
- Link status and reason
- Source and destination device/interface
- Endpoint IPv4 address and prefix
- Interface operational state
- Routed, access, or trunk mode
- Access VLAN or trunk native/allowed VLAN information

## Interface hover details

Hover over an interface label below a topology device to view its IP, mode,
VLAN, state, and connected peer.
