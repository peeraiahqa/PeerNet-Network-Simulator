# Ping and Traceroute Source IP Update

Both network tools now display **Source IP** and **Destination IP** side by side.

- Source IP choices come from the interfaces configured on the selected source
  device.
- Devices with multiple routed interfaces can select the required source IP.
- A clear validation message is shown when the selected device has no IP.
- Ping, Traceroute, Events, and Packet Analysis record the selected source IP.
